The release contains only WAV audio: seven tracks plus the continuous master.
Each file is 48 kHz / 24-bit stereo and includes its title, artist, album,
front-cover artwork, CC BY-NC 4.0 notice, and the original SoundFont credits.
Some players do not display embedded WAV artwork.

The [main README](../../README.md) explains the image encoding, fly-brain
simulation, neural-to-music mappings, and compositional logic.
[Prompts](artwork/prompts.json), [neural measurements](neural/provenance.json),
[composition](composition.json), [validation](validation.json), and
[release manifest](release_manifest.json) document the experiment.
Standalone image binaries, MIDI scores, and MP3 listening copies remain local.
Exact neural reruns require the original source images and model data.

Check downloads with `shasum -a 256 -c SHA256SUMS` from a folder containing the
eight WAVs and this repository's [SHA256SUMS](SHA256SUMS) file.
